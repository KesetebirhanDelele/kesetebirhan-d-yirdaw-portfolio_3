# Utility Company Customer Service Response Index (CSRI): Beginning 2005

## Project Overview

Provides insights into utility company performance by analyzing customer service response metrics, helping organizations improve their service delivery.

---

## Business Problem

Utility companies face challenges in managing customer complaints effectively, leading to increased response times and escalations. Without improvements in operational efficiency, these issues are likely to worsen, impacting customer satisfaction and trust.

---

## Objective

- Automate routine customer inquiries to reduce operational costs.
- Utilize historical complaint data to predict and manage resource allocation.
- Enhance customer satisfaction by improving response times and reducing escalations.

---

## Tools & Technologies

- Microsoft Fabric
- Numtra
- Power BI
- Logistic Regression
- Decision Trees
- Random Forest
- XGBoost
- XGBRegressor

---

## Project Workflow

- Clean and standardize the Utility Customer Service Response Index dataset from 2005 to 2025.
- Analyze patterns in complaint data using machine learning algorithms.
- Evaluate model performance metrics to select the best predictive model.
- Visualize insights and trends through interactive dashboards in Power BI.
- Implement automation for routine inquiries to improve efficiency.

---

## Key Insights

- The dataset includes metrics like initial complaints, escalated complaints, and response times, which are critical for operational analysis.
- Machine learning models achieved perfect scores for R-squared and Variance, indicating strong fit to the training data.
- Despite high model accuracy, some errors were noted, suggesting the need for careful management of outliers.
