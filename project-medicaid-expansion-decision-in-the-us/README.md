# Medicaid Expansion Decision in the US

## Project Overview

Analyzes Medicaid expansion's effects on healthcare access and outcomes using data visualizations to present findings.

---

## Business Problem

Medicaid expansion is a critical program that aims to provide affordable health coverage, but some states resist this initiative, limiting access for vulnerable populations. This project analyzes the impact of Medicaid expansion by comparing states that adopted the program with those that did not, focusing on health outcomes and insurance trends.

---

## Objective

- Analyze state health reports and insurance trends from 2015 to 2020.
- Create a comprehensive Tableau dashboard to visualize the data.
- Provide insights to help states evaluate the benefits of Medicaid expansion.

---

## Tools & Technologies

- Tableau
- Excel
- Health reports
- Insurance trend data
- Underlying cause of death data

---

## Project Workflow

- Import relevant data sets including health status and insurance coverage.
- Set up a custom-sized Tableau dashboard for visual representation.
- Design and arrange various visual components such as graphs and KPIs.
- Analyze and compare data from states that expanded Medicaid versus those that did not.
- Finalize the dashboard for presentation and insights.

---

## Key Insights

- The analysis covers health insurance trends from 2015 to 2020.
- The dashboard includes key performance indicators related to health reports and causes of death.
- Visualizations help illustrate the disparities in health coverage among states.
